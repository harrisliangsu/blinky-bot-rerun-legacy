# Install BlinkyBot

BlinkyBot Phase 1 installs as a Mac app. Download the disk image from the
[GitHub releases](https://github.com/harrisliangsu/blinky-bot/releases), drag BlinkyBot into
Applications, and open it. The app starts a local engine and the Compose UI on this Mac. Docker
is not required, and a Supabase project is not required.

The install steps, the drag-to-Applications disk image, and the from-source loop are in the
[README](README.md).

The upstream Rerun server install (Docker and Supabase) is a different path, and it is not Phase 1:
[docs/upstream-server.md](docs/upstream-server.md).
